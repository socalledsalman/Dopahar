# **Dopahar**

A minimal, 100% offline, ad-free daily planner for Android. No accounts, no tracking, no cloud lock-in—all your data stays locally on your device.

---

## **What's New in v1.4.2**

* **Dynamic Header Date View:** Tapping the top-left header date opens a quick date jumper (`Prev Day`, `Today`, `Next Day`, or any calendar date) and updates the header title and dashboard sections (`Habits`, `Schedule`, `Tasks`, `Spend`, and `Reflection`) to match the selected date.
* **Threshold Budget Coloring:** Budget overview and category cards automatically shift color zones based on monthly spend—green up to 80%, yellow between 80% and 95%, and red above 95% or over budget.
* **Consistent Release Signing:** Standardized release keystore signing so future updates install smoothly in place without losing local data.

---

## **Features**

* **Today Dashboard** — Quick-add strip, daily stats, 7-day snapshot, Plan Tomorrow queue, and a 3-line daily reflection with mood tracking.
* **Habits** — 7-day and 14-day tracking grids, 30-day heatmaps, and Rest Day (freeze) tokens to protect streaks.
* **Schedule & Routines** — Hourly time-blocking timeline, reusable daily routines, offline reminders, and `.ics` calendar export.
* **To-Do List** — Priority levels, swipe-to-complete/reschedule gestures, and automatic rollover for unfinished tasks.
* **Budget & IOUs** — Monthly spend limits with dynamic threshold zones, category breakdowns, search/filters, and a dedicated Lent/Borrowed (IOU) tracker.
* **Focus Detox** — Focus timer and stopwatch with Android Screen Pinning, plus one-tap task/block linking.
* **Privacy & Security** — 4-digit PIN lock with native Android Fingerprint unlock.
* **Personalization** — AMOLED, Dark, and Light surfaces, 5 bundled offline fonts, and a custom accent color wheel.
* **Backup & Restore** — Export/share local JSON backups anytime, or connect optional Google Drive auto-sync.

## **Download & Install**

1. Open the [**Releases**](https://github.com/socalledsalman/Dopahar/releases) page.
2. Download **`Dopahar-v1.4.2.apk`** (from the **`Dopahar-v1.4.2-APK`** build artifact) under **Assets**.
3. Install the APK on your Android device *(if upgrading from a build prior to `v1.4.2`, export a JSON backup in Settings first and do a one-time clean reinstall; all future updates from `v1.4.2` onward will install in place)*.
